## [1.0.0] - 2025-05-16

### Added

- Daily symptom diary with 1-5 intensity scale per symptom type
- Two-user support with configurable names
- Automatic weather context (temperature, humidity, wind, condition) via Open-Meteo
- Automatic pollen context (birch, grasses, ambrosia, mugwort, alder, hazel) via Open-Meteo
- History view to browse past entries with associated weather and pollen data
- Data export functionality
- Location settings (latitude, longitude, city name)
- Multi-stage Docker build for self-hosting
- PostgreSQL persistence via Prisma 7 ORM
